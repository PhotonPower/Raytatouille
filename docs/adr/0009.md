# ADR 0009: Fehlerbehandlung

**Status:** angenommen (2026-10-04)

## Entscheidung

Exceptions nur an API-Grenzen (Laden, Eingabeprüfung, `rtt::io::ParseError`). In Tracing-Schleifen keine Exceptions; Strahlprobleme sind Status-Flags. Semantische Modellfehler liefert `rtt::model::validate` als Diagnosen.

## Verworfen

Exceptions pro Strahl.
