# ADR 0011: Plattformen und Compiler

**Status:** angenommen (2026-10-04)

## Entscheidung

Linux und Windows. In der CI getestet: GCC 13, Clang 18, MSVC 2022. Kein `-ffast-math` bzw. `/fp:fast`. Bitgleichheit ist je Plattform und Compiler garantiert, nicht plattformübergreifend.

## Verworfen

macOS.
