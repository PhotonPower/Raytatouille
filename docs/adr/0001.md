# ADR 0001: Kern in C++20 mit CMake und vcpkg

**Status:** angenommen (2026-10-04)

## Entscheidung

Vorgabe des Teams. C++20 läuft identisch auf Linux und Windows und hat ein reifes Numerik-Ökosystem. CMake ≥ 3.25 mit Presets; Abhängigkeiten über vcpkg im Manifest-Modus (`vcpkg.json`, fester `builtin-baseline`). Für lokale Entwicklung unter Linux dürfen Systempakete verwendet werden (Preset `dev`).

## Verworfen

Rust; reines Python/JAX (verzweigende Strahlpfade schlecht abbildbar).
