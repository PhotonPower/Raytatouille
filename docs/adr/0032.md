# ADR 0032: Pupillenfunktion und Wellenfront-Auswertung

**Status:** angenommen (2026-10-10)

## Kontext

M6 (Beugung) braucht eine gemeinsame Grundlage für Zernike-Fit, FFT-PSF, MTF, Encircled Energy und die Jones-Pupille (#199, M6-Plan; Entscheidungen H1 bis H12 im Issue). Dieses ADR legt diese Grundlage fest: die Pupillenfunktion, die Koordinaten der Beugung, den Through-Focus-Bezug, den Zernike-Fit und die Strehl-Näherung. Die FFT-Beugung selbst folgt in ADR 0033 (#200), die Polarisation in der Pupille in ADR 0034 (#201).

**Ist-Stand (main nach 0.7.0):**
- **OPD** (`rtt/analysis/opd.hpp`, #29, #102, #168):
  - Funktionen `opd_points` (beliebige `PupilSampling`), `opd_map` (`GridPupil`, nur Punkte im Einheitskreis) und `opd_fan`.
  - Referenzsphäre:
    - Mittelpunkt C ist der reale Durchstoßpunkt des Hauptstrahls der Referenzwellenlänge auf der Bildfläche.
    - Der Radius R ist der Abstand zur Mitte der paraxialen Austrittspupille E = (0, 0, z_XP); R = +∞, wenn die XP im Unendlichen liegt.
    - Die OPL bis zur Sphäre wird auslöschungsfrei berechnet (opd.cpp, `opl_to_sphere`).
  - Konventionen:
    - W = OPL_ref − OPL in Wellen bei λ_ref; Bezugsstrahl ist der Hauptstrahl derselben Wellenlänge.
    - Vignettierte Punkte haben W = 0 und ihren Status.
- **Pupillenkoordinaten (px, py):**
  - Normiert auf den paraxialen EP-Radius; +y ist meridional.
  - Beim realen Zielen ist das Ziel (px R_s, py R_s) auf der Blendenfläche (`aim_ray`). Ist der Objektraum telezentrisch, sind es Steigungen.
  - Eine Abbildung auf die Austrittspupille gibt es nicht.
- **Was fehlt:** volles Raster, Zernike-Auswertung und eine Liste beliebiger Pupillenpunkte als `PupilSampling`.
  - Im Modell gibt es nur `ZernikeSag` (Noll, j = 1 an Index 0); compile lehnt es ab (M8).
- **Pfade mit Kristall-Modi:** `first_order` lehnt sie ab, die OPD ist dort also blockiert (Wächtertest in test_opd.cpp; #35, Kommentar 6071084114).

## Entscheidung

### 1. Raster: N×N Zellen mit Flächenanteil

**Zellen:**
- Das Einheitsquadrat [−1, 1]² wird in N×N Zellen der Kantenlänge a = 2/N geteilt, N ≥ 2, Standard 64.
- Zelle (i, k) mit i, k = 0 … N−1 hat die Mitte (−1 + (i + ½) a, −1 + (k + ½) a).
- Die Reihenfolge ist zeilenweise von py = −1 aufwärts, px läuft am schnellsten (wie `GridPupil`).
- Bei geradem N liegt keine Zellmitte auf der Achse; der Hauptstrahl wird ohnehin eigens getraced (Bezug).

**Flächenanteil f ∈ [0, 1]** (H2b) ist der Anteil der Zellfläche im Einheitskreis, exakt in geschlossener Form (hergeleitet).
- Für die Zelle [x₀, x₁] × [y₀, y₁] und t ∈ [x₀, x₁] mit |t| < 1 ist h(t) = √(1 − t²). Die Länge des Schnitts in y ist ℓ(t) = max(0, min(y₁, h) − max(y₀, −h)).
- An den Knickstellen t = ±√(1 − y₀²) und ±√(1 − y₁²) zerfällt [x₀, x₁] in Teilstücke. Auf jedem Teilstück ist ℓ eine der Formen y₁ − y₀, h − y₀, y₁ + h, 2h oder 0.
  - Die Form entscheidet sich in der Mitte m des Teilstücks: oben h, wenn h(m) ≤ y₁; unten −h, wenn −h(m) ≥ y₀.
  - Das „≤“ ist nötig: Bei ungeradem N berührt eine Zellkante y = ±1 den Kreis in t = 0. Dort ist h ≤ y₁ auf dem ganzen Teilstück mit Gleichheit nur in einem Punkt, und mit „<“ wäre die Fläche falsch (Wegwerfskript: Σ f a² − π = 1,3·10⁻² bei N = 3).
- Mit der Stammfunktion P(t) = ½ (t √(1 − t²) + arcsin t) von h gilt f = (1/a²) Σ ∫ ℓ dt.
- Schwerpunkt der Teilfläche, ebenso geschlossen:
  - x̄ aus ∫ t ℓ dt mit ∫ t h dt = −⅓ (1 − t²)^(3/2);
  - ȳ aus ∫ ½ (oben² − unten²) dt mit h² = 1 − t², also ∫ h² dt = t − t³/3.
- Prüfungen:
  - Σ f a² = π bis auf Rundung;
  - Symmetrie;
  - Vergleich mit einer feinen Mittelpunktsregel im Test.

**Abtastpunkt:**
- Volle Zellen (f = 1): die Mitte.
- Randzellen (0 < f < 1): der Schwerpunkt ihrer Teilfläche im Kreis. Er liegt immer innen (|p| < 1), der Strahl trifft die Blende also nicht genau auf dem Rand.
- Zellen mit f = 0 werden nicht getraced.

### 2. Strahlen: Punktliste als neue `PupilSampling`

- rtt-trace bekommt eine neue Alternative `PointListPupil { std::vector<PupilPoint> points; }`, hinten an `PupilSampling` angehängt; die Indizes der bestehenden Alternativen bleiben.
  - `pupil_points` gibt die Liste unverändert zurück.
  - Jeder Punkt muss endlich sein, sonst `std::invalid_argument`.
  - Spot, Ghost-Ranking und Pfad-Analysen nehmen sie wie `RandomPupil`.
- Das ist eine Änderung am öffentlichen Header einer anderen Bibliothek. Sie kommt nach Regel 8 als eigener PR vor V1 (#202), mit diesem ADR als Grundlage.
- Gezielt und getraced wird wie bei `opd_points`, mit derselben Referenzsphäre (Punkt 5 für den verschobenen Fokus). Die Pupillenfunktion ist also auf ihren Punkten bitgleich zu `opd_points` mit derselben Punktliste.

### 3. Pupillenfunktion

    struct PupilFunctionOptions {
      int grid = 64;                 // N >= 2
      double apodization = 0.0;      // Gauss factor G >= 0, A_apod = exp(-G rho^2)
      double focus_shift = 0.0;      // mm along d_c (point 5)
      trace::Aiming aiming = trace::Aiming::Real;
      bool with_prt = false;         // copy the accumulated P per point (ADR 0034)
      double lost_warning_fraction = 0.5;
      double mapping_warning = 1e-2; // point 4
    };

    struct PupilFunction {
      std::uint16_t field, wavelength;
      int grid;                      // N
      ReferenceSphere sphere;        // after focus_shift
      // per cell, N*N entries in the order of point 1:
      std::vector<double> fraction;  // f
      std::vector<double> px, py;    // sample point (centre or centroid)
      std::vector<double> amplitude; // sqrt(weight) * exp(-G rho^2); 0 if not arrived or f = 0
      std::vector<double> w;         // waves at lambda_ref; 0 if not arrived or f = 0
      std::vector<trace::RayStatus> status;
      std::vector<std::complex<double>> prt; // 9 per cell if with_prt, global, row-major (3 row + col) as RayBatch
      std::optional<PupilMapping> mapping;   // point 4; none for an afocal image space
      double arrived_fraction;       // sum f over arrived cells / sum f over all cells
      RayLosses losses;
      std::vector<model::Diagnostic> warnings;
    };

    struct PupilMapping {            // point 4
      std::array<double, 4> m;       // M row-major: rows s_x, s_y; columns px, py; dimensionless
      std::array<double, 2> s0;      // s of the chief ray of this wavelength (0 at lambda_ref)
      math::Vec3 centre;             // origin of the PSF plane: C' (after focus_shift), global, mm
      math::Vec3 e_x, e_y, d_c;      // global unit vectors (d_c: chief ray of lambda_ref)
      double delta_max, delta_rms;   // |s - s0 - M p| / ||M||_2, pupil units
    };

- **Amplitude:**
  - A = √weight · A_apod.
  - weight ist die Leistung des Strahls (ADR 0021, inklusive Coatings und Absorption, unpolarisiert).
  - A_apod nach OpticStudio mit ρ des Abtastpunkts.
  - Der Flächenanteil f bleibt getrennt; der Verbraucher multipliziert ihn (ADR 0033: Zellwert f A e^(−2πi W λ_ref/λ), Vorzeichen nach „Bezeichnungen“).
- **Status:**
  - Zellen mit f = 0 werden nicht getraced. Sie stehen mit Status `Vignetted` und A = W = 0 in der Liste; f = 0 kennzeichnet sie, und in `losses` zählen sie nicht.
  - **Wer Zellen zählt oder auswertet, prüft zuerst f > 0 und dann `status`.** Das steht so im Doxygen von `PupilFunction`; sonst zählten die Zellen außerhalb des Kreises als vignettiert.
  - `rays.lost` und `stop.clips_beam` gelten wie bei der OPD-Karte.
- `opd_map` und die bestehenden Analysen bleiben unverändert.

### 4. Koordinaten der Beugung (H3)

Die Fraunhofer- bzw. Debye-Beugung ist eine Fourier-Transformation über die Richtungssinus im Bildraum (ADR 0033). M6 tastet gleichmäßig in p ab und ordnet linear zu.

**Ebene und Richtungssinus:**
- Die PSF-Ebene steht senkrecht zu d_c durch C. Ihre Achsen sind:
  - e_x = normiert(x_B − (x_B · d_c) d_c), mit x_B der lokalen x-Achse der Bildfläche;
  - e_y = d_c × e_x.
  - d_c ist die Endrichtung des Hauptstrahls der Referenzwellenlänge; der Rahmen ist also für alle Wellenlängen derselbe.
  - Ist |x_B × d_c| ≤ 10⁻⁶ (streifender Hauptstrahl), ist der Rahmen nicht definiert: `AnalysisError` mit `location` der Bildfläche (Fläche des letzten Ereignisses), wie in ADR 0034. Dieselbe Regel und denselben Rahmen nimmt ADR 0034 für die Ausgangsbasis der Jones-Pupille; Jones-Pupille, Stokes-Karte und PSF stehen damit in denselben Achsen.
- Auf der Achse sind das die Achsen der Bildfläche.
- Richtungssinus eines Strahls: s = n′ (d · e_x, d · e_y).

**Affine Zuordnung s ≈ s₀ + M p** mit der 2×2-Matrix M = ∂s/∂p bei p = 0, je ausgewerteter Wellenlänge:
- s₀ ist s des Hauptstrahls dieser Wellenlänge, 0 bei λ_ref. Der Farbquerfehler steckt als Tilt schon in W (Referenzsphäre um C); s₀ dient nur der Kennzahl.
- M kommt aus zentralen Differenzen an vier parabasalen Strahlen derselben Wellenlänge bei p = (±δ, 0) und (0, ±δ), δ = 10⁻³, dem δ der Bildfeldwölbung. Der Fehler ist O(δ²).
- Begründung gegenüber der rein paraxialen NA aus `first_order`:
  - M enthält Orientierung und Spiegelung (Faltungen, reelles oder virtuelles Bild) und die Verkürzung außer der Achse in einer Richtung, ohne eigene Vorzeichenregeln.
  - Auf der Achse eines rotationssymmetrischen Systems ist M bis O(δ²) diagonal mit Beträgen n′|u′| (u′ paraxiale bildseitige Randstrahlsteigung), also der paraxiale Maßstab. Die Vorzeichen je Achse folgen aus der Geometrie. Beispiel: Beim Hohlspiegel auf der Achse, dessen Bildfläche ungedreht ist (lokale x-Achse = globale +x), ist M = n′|u′| · diag(−1, 1); ein um y gedrehter Detektor kehrt das Vorzeichen um.
- Afokaler Bildraum: M ist singulär (|det M| ≤ 10⁻¹² n′²). `mapping` fehlt dann; Analysen, die die Zuordnung brauchen (ADR 0033), lehnen ab.

**Kennzahl:**
- δ_map = max_k |s_k − s₀ − M p_k| / ‖M‖₂ über die angekommenen Zellen mit f > 0 (‖M‖₂ größter Singulärwert), in Pupilleneinheiten; dazu der RMS-Wert.
- Über `mapping_warning` (Standard 10⁻²) kommt die Warnung `pupil.mapping_nonlinear` mit `location` = `/paths/i`.

**Grenze (dokumentiert):**
- Die Zuordnung ist genau dann linear, wenn die Abtastung im Objektraum gleichmäßig in sin U ist und das System die Sinusbedingung n h sin U = n′ h′ sin U′ erfüllt (Sasián, Folie 29).
- Das reale Zielen tastet gleichmäßig auf der Blende ab. Bei endlichem Objekt ist das nicht gleichmäßig in sin U; außerdem verletzen Koma und Pupillenaberration die Bedingung.
- Beispiel Paraboloid, Objekt im Unendlichen: Strahlhöhe h, Brennweite f, Abstand zum Brennpunkt f + h²/(4f), also sin U′ = h/(f + h²/(4f)) und relativ (h/2f)² am Rand, 6,25·10⁻⁴ bei F/10.
- Inverses Zielen auf ein Raster in s folgt nach M6.

### 5. Through-Focus: verschobener Bezugspunkt

- `OpdOptions` bekommt `double focus_shift = 0.0` (mm), ebenso `PupilFunctionOptions`.
- Der Mittelpunkt der Referenzsphäre wird C′ = C + Δ d_c; Δ > 0 heißt in Ausbreitungsrichtung des Hauptstrahls.
- Radius und Ast:
  - R′ = |C′ − E| und Ast = sign(d_c · (C′ − E)) wie in opd.cpp;
  - R = ∞ bleibt ∞;
  - C′ = E ist ein `AnalysisError` wie heute „exit pupil lies on the image surface“.
- Danach unverändert `opl_to_sphere` mit C′, R′. Bei Δ = 0 ist das Ergebnis bitgleich zu heute.
- **Exakt ohne erneutes Tracen:** Die OPL bis zur Sphäre folgt aus Ort und Richtung des Strahls auf der Bildfläche, und der Bildraum ist homogen; die Bildfläche ist nur Endpunkt. C′ liegt auf dem Hauptstrahl, also bleibt W(0, 0) = 0 bei λ_ref.
- **Sollwert für Tests (hergeleitet):** Eine perfekte Kugelwelle konvergiere nach C. Ein Strahl mit Richtung u und cos α = u · d_c kreuzt die Sphäre um C′ im Abstand s vor C:
  - |−Δ d_c − s u|² = R′², also s = −Δ cos α + √(R′² − Δ² sin² α);
  - für den Hauptstrahl ist s_c = R′ − Δ.
  - Damit gilt W = n′ (s − s_c) = n′ [Δ (1 − cos α) + √(R′² − Δ² sin² α) − R′] (in mm; in Wellen durch λ_ref).
  - Der Test rechnet die letzten beiden Terme auslöschungsfrei: √(R′² − Δ² sin² α) − R′ = −Δ² sin² α / (√(R′² − Δ² sin² α) + R′). Die direkte Differenz verliert bei R′ = 10⁶ mm etwa 10⁻¹⁰ mm, mehr als die Rundung des Codes (Hinweis 13).
  - Für R′ → ∞ geht das gegen n′ Δ (1 − cos α).
  - Für 0 < Δ ≪ R′ ist W > 0: Die Welle krümmt sich stärker als die flachere Referenz, passend zum Vorzeichen W > 0 = „vorauseilend“. Mit kleinem α ist W ≈ n′ Δ α²/2, also W020 ≈ Δ NA²/(2 n′).
- Der Test (V1) misst α aus den getraceten Richtungen, unabhängig vom Code der Sphäre.

### 6. Zernike-Fit (H2a: Noll)

- **Polynome:**
  - Z_j nach Niu/Tian Gl. (3): √(2(n+1)) R_n^m(ρ) cos mθ für gerade j, √(2(n+1)) R_n^m(ρ) sin mθ für ungerade j, jeweils m ≠ 0; √(n+1) R_n^0 für m = 0.
  - R_n^m nach Gl. (4); j ↔ (n, m) nach Gl. (8) und (9).
  - Orthonormal im Sinn von Gl. (7): Mittelwert über den Einheitskreis. Gleiche Reihenfolge wie `ZernikeSag`.
- **Normierungsradius:** der Rand der normierten Pupille, ρ = |p| ≤ 1.
- **Umfang:** j = 1 … J, Standard J = 37 (das ist n ≤ 7 vollständig plus Z₈⁰), höchstens J = 231 (n ≤ 20).
- **Auswertung von R_n^m:**
  - Die Koeffizienten c_s von Gl. (4) sind ganze Zahlen. Sie werden exakt in uint64 gerechnet (20! < 2⁶⁴) und sind bis n = 20 kleiner als 2⁵³ (größter Betrag 2 333 760), also exakt in double.
  - Ausgewertet wird R = ρ^m · Σ_s c_s (ρ²)^(K−s), K = (n − m)/2, nach Horner in x = fl(ρ²); ρ^m durch m Multiplikationen.
  - **Fehlerschranke (hergeleitet aus dem Rundungsmodell fl(a ∘ b) = (a ∘ b)(1 + ε), |ε| ≤ u = 2⁻⁵³):** |R̂ − R| ≤ γ_k · Σ_s |c_s| ρ^(n−2s) mit k = 3K + m + 1 und γ_k = k u/(1 − k u). Je Horner-Schritt kommen zwei Rundungen hinzu, die Rundung von x wirkt höchstens K-fach, dazu ρ^m und eine Reserve.
  - Die Auslöschung bei großem n steckt in Σ |c_s| ρ^(n−2s): Bei n = 20 sind das einige 10⁶. 13 hat bei n = 20, m = 0, ρ = 0,975 einen tatsächlichen Fehler von 2,5·10⁻¹⁰ gemessen (Horner, gegen exakte Brüche).
  - Der Test prüft genau diese Schranke gegen exakte Brüche, für alle (n, m) bis n = 20 und ρ = 0 … 1 in Schritten von 10⁻³. Für den Fit ist ein Fehler dieser Größe bedeutungslos.
- **Fit:** gewichtete kleinste Quadrate über die angekommenen Zellen mit f > 0, Gewicht f (Flächenanteil).
  - Gleichungen: Aᵀ F A c = Aᵀ F W, F = diag(f). Das ist Gl. (54) mit Gewichten, die Riemann-Summe von Gl. (7) bzw. Tabelle 10 (hergeleitet).
  - Die Amplitude A geht bewusst nicht ein: Die Koeffizienten beschreiben die Wellenfront, nicht ihre Ausleuchtung.
  - Gelöst wird mit der Cholesky-Zerlegung nach MNT Alg. A.4 (in rtt-analysis/detail, weil rtt-optim höher liegt).
  - **Konditionierung:**
    - Weniger angekommene Zellen mit f > 0 als J ergeben einen `AnalysisError` (`location` = `/paths/i`, Meldung mit der Zahl der Zellen und J).
    - Ebenso ein Pivot d_j ≤ 10⁻⁸ · max_i (AᵀFA)_ii in der Cholesky-Zerlegung: Die Normalgleichungen wären dann so schlecht konditioniert, dass die Koeffizienten etwa acht Stellen verlören.
    - Auf dem vollen Kreis ist AᵀFA/Σf ≈ I (Gl. (7) als Riemann-Summe), die Pivots liegen also nahe Σf.
- **Ergebnis:**
  - c_j in Wellen bei λ_ref;
  - Rest-RMS der Wellenfront nach dem Fit (f-gewichtet);
  - σ, die f-gewichtete Standardabweichung von W (nur Piston entfernt);
  - Zahl der Zellen, `arrived_fraction`.
  - Auf dem vollen Kreis ist σ² ≈ Σ_{j≥2} c_j² (Tabelle 10); auf dem diskreten Raster gilt das nur näherungsweise (§5). Deshalb rechnet der Code σ direkt.
- **Warnung `zernike.pupil_incomplete`** (`location` = `/paths/i`): wenn 1 − `arrived_fraction` > `incomplete_warning_fraction` (Standard 10⁻²). Auf einer unvollständigen Pupille sind die Z_j nicht orthogonal (§5); die Koeffizienten sind dann ein Fit, keine Zerlegung.
- Fringe als Umrechnung später (H2a).

### 7. Strehl-Näherung (Maréchal)

- σ_BF: f-gewichtete Standardabweichung von W nach Abzug von Piston, Tilt und Defokus, also nach einem eigenen Fit mit Z₁ … Z₄. Das ist die Varianz um den Beugungsfokus (Wyant/Creath S. 38). Ein eigener kleiner Fit ist nötig, weil die Z_j auf dem Raster nicht exakt orthogonal sind; die Koeffizienten des großen Fits zählen hier nicht.
- S ≈ exp(−(2π σ_BF λ_ref/λ)²) nach Gl. (67) bei der ausgewerteten Wellenlänge λ. Der Faktor λ_ref/λ rechnet W in Wellen bei λ um.
- Gültig etwa ab S ≥ 0,1 (Quelle). Darunter wird die Zahl trotzdem ausgegeben; Doku statt Warnung.
- Gleichförmige Ausleuchtung vorausgesetzt (Gl. (64) mit A = 1); die Amplitude geht nicht ein.
- Die exakte Strehl-Zahl aus der PSF-Spitze kommt mit ADR 0033.

### 8. Apodisation

- Nur als Analyse-Option (H8, H9): Gauß nach OpticStudio, A_apod = e^(−Gρ²), G ≥ 0. Andere Werte, auch nicht endliche, sind `std::invalid_argument`.
- Kein Feld im Dateiformat, kein Schemasprung.

### 9. Grenzen und Fehler

- **Pfade mit einem ordinären oder extraordinären Ereignis** (H6): Pupillenfunktion, Zernike-Fit und Strehl-Näherung werfen vor dem Tracen einen `AnalysisError` „paths with crystal modes are not supported (#35)“ mit `location` = `/paths/i`. Heute käme ein `ParaxialError` aus `first_order`. Der Wächtertest in test_opd.cpp bleibt.
- Fehler sind `AnalysisError` mit Ortsangabe, ohne Code (docs/diagnostics.md, „Ausnahmen mit Ortsangabe“). Codes gibt es nur für Warnungen; das gilt ebenso für ADR 0034 (abgestimmt in #213).
- Optionen außerhalb ihres Bereichs (grid < 2, J < 1 oder > 231, Schwellen nicht in [0, 1], G < 0, Δ nicht endlich): `std::invalid_argument`.
- Neue Warncodes (ADR 0022, Producer `analysis`, Zeilen in docs/diagnostics.md):
  - `pupil.mapping_nonlinear`, Pointer auf den Pfad;
  - `zernike.pupil_incomplete`, Pointer auf den Pfad.

## Verworfen

- **Treppe (nur Zellen mit Mitte im Kreis, f ∈ {0, 1}):** Der Randfehler ist O(h) in der Fläche und verschiebt Airy-Nullstelle und MTF. Um die Toleranz 10⁻³ zu erreichen, bräuchte es ein deutlich größeres N (H2b).

- **Strehl aus den Koeffizienten des großen Fits:** Auf dem Raster sind die Z_j nicht exakt orthogonal (§5). Ein eigener Fit mit Z₁ … Z₄ ist exakt die minimale Varianz.
- **Fringe-Reihenfolge:** Entscheidung des Maintainers (H2a), später als Umrechnung.
- **Eigen (LLT oder QR) für den Fit:** rtt-optim hat Eigen wegen `-Wnull-dereference` von GCC 16 bei -O2 durch Alg. A.4 ersetzt (#166). Das gilt hier ebenso.

## Nachtrag (#205, 2026-10-11): bekannte Grenze, zentral abgeschattete Pupillen

Pupillenfunktion, PSF, MTF und EE (ADR 0033) gehen bei einer zentralen Abschattung (Ringapertur, `inner_radius` > 0, etwa ein Cassegrain) nicht. Der Grund: Der Hauptstrahl, der die Referenzsphäre und d_c festlegt (Punkte 4 und 5), und die parabasalen Strahlen der Zuordnung M bei |p| = 10⁻³ fallen in die Abschattung. Eine Abhilfe (Bezug ohne Hauptstrahl, M aus Strahlen außerhalb der Abschattung) ist #229 („Analysen für zentral abgeschattete Systeme“), für Spot, OPD und Pupillenfunktion gemeinsam.

## Nachtrag (#229, 2026-10-11): virtuelle Referenzstrahlen bei zentraler Abschattung

Löst die bekannte Grenze aus dem Nachtrag #205. Mit dem Koordinator abgestimmt (Plan zu #229, Fragen 1 bis 6).

**Referenzstrahlen und Stichprobenstrahlen:**
- *Referenzstrahlen* legen einen Bezug fest. Das sind der Hauptstrahl, aus dem C, d_c und die Referenzsphäre folgen (Punkte 4 und 5), die vier parabasalen Strahlen der Zuordnung M (Punkt 4), die ±δ-Strahlen der Bildfeldwölbung, die Haupt- und Zonenstrahlen der Farbfehler und der Hauptstrahl des Spot-Bezugs, auch im Optimierer (`SpotReference::Chief`).
- *Stichprobenstrahlen* bilden ab: Spot- und OPD-Abtastung, die Zellen der Pupillenfunktion, Geister und aufgezeichnete Pfade.
- Referenzstrahlen werden **immer virtuell** getraced: ohne die Prüfung des Innenradius kreisförmiger Aperturen (`inner_radius` > 0, die zentrale Abschattung). Jeder äußere Rand und alle übrigen Aperturformen vignettieren wie bisher.
- Stichprobenstrahlen bleiben real.

**Warum immer und nicht nur als Rückfall:**
- Ein Strahl, der keinen Innenrand trifft, läuft virtuell bitgleich wie real, denn es entfällt nur der Vergleich r² ≥ r_i². Ohne Abschattung ändert sich also kein Ergebnis.
- Mit Abschattung ist der virtuelle Hauptstrahl bitgleich der reale Hauptstrahl desselben Systems ohne Abschattung. Das ist der gewünschte Bezug: Die Referenzsphäre, d_c und M hängen nicht davon ab, ob die Pupillenmitte Licht durchlässt.
- Die Flächenformeln sind in der Abschattung stetig fortgesetzt; Sag und Normale sind dort definiert.
- Ein Rückfall „erst real, dann virtuell“ gäbe dasselbe Ergebnis mit einer zweiten Verzweigung.

**Zuordnung M aus virtuellen parabasalen Strahlen** statt aus einem Ring knapp außerhalb der Abschattung (Vorschlag im Issue, verworfen):
- M ist die Ableitung ∂s/∂p bei p = 0 (Punkt 4), gebildet als zentrale Differenz bei δ = 10⁻³ mit einem Fehler O(δ²).
- Ein Ring bei |p| ≥ ε misst eine Sekante. Beim Paraboloid F/10 läge sie relativ um etwa (ε/(4F))² neben M, bei ε = 0,4 also 10⁻⁴. Die M-Wache der PSF-Abnahme (#205, Toleranz 2(δ/(4F))² + 10⁻¹² ≈ 1,3·10⁻⁹) würde dann scheitern, obwohl M nicht falsch ist.
- δ_map misst die Linearität weiter über die angekommenen Zellen, also über den Ring.

**`AnalysisError` (ADR 0022, Punkt 5)** bleibt für Referenzstrahlen, die auch virtuell verloren gehen: äußerer Rand, TIR, Missed, keine Konvergenz. Die Fehlersemantik (Meldung, Fläche, Ort) ändert sich nicht.

**Schnittstelle in rtt-trace** (Regel 8; diese Entscheidung ist ihre Grundlage):
- `RayBatch::set_ignore_obscurations(bool)` und `ignores_obscurations()`, nach dem Muster von `enable_q()` (ADR 0034, Nachtrag #207): eine Eigenschaft des ganzen Stapels, aus bei einem neuen Stapel, erhalten von `resize()`. Der sequenzielle Tracer gibt sie als `RayState::ignore_obscurations` an `sequential_step()` weiter.
- `inside_aperture(surface, hit, ignore_inner)` als Überladung; die bisherige Form ruft sie mit `false` auf.
- Der nicht-sequenzielle Tracer (Geister) liest das Flag nicht; seine Strahlen sind Stichproben.
- `trace::stop_radius(system, path, wavelength)` gibt |R_s|, den Stoppradius zu |p| = 1 aus dem Zielkontext von `aim_ray()`: r_ep mal die paraxiale Stopphöhe je Einheit EP-Höhe, telezentrisch u_m mal die Stopphöhe je Einheit Steigung.
  - Mit realem Zielen trifft der Strahl des Pupillenpunkts p den Stopp bei |p| |R_s|, innerhalb von `kAimTolerance`. Eine zentrierte Abschattung vom Radius r_i am Stopp ist also der Pupillenkreis |p| = r_i/|R_s|.
  - Die Pupillenfunktion braucht das für die Ringzellen (#229, PR C). Ohne die Funktion müsste die Analyse den Zielkontext nachbauen.

**Warnung `stop.clips_beam`** (ADR 0023): gilt nur noch für Strahlen, die am Stopp **außerhalb** seines Innenradius vignettiert werden. Ein Strahl in der Abschattung des Stopps ist kein Beschnitt des Bündels durch den Stopp. Der vignettierte Strahl steht am Auftreffpunkt, sein lokaler Radius ist also bekannt. `rays.lost` zählt die Abschattung weiter.

**Geltungsbereich und Grenzen:**
- Der virtuelle Bezug gilt für eine Abschattung auf **jeder** Fläche des Pfads, vor, am oder hinter dem Stopp, etwa für den Sekundärspiegel eines Cassegrain vor dem Primärspiegel als Stopp: Referenzstrahlen prüfen keinen Innenradius. Das Zielen ignoriert Aperturen ohnehin (`aim_ray`), also scheitert auch die Zielung des Hauptstrahls an keiner Abschattung (Zweitprüfung #238).
- Nur die Flächenanteile der Ringzellen (PR C) setzen eine Abschattung **am Stopp** voraus, weil nur dort ihr Rand der Pupillenkreis |p| = r_i/|R_s| ist. Eine Abschattung auf einer anderen Fläche wird von den Zellen real getraced, also als Treppe am Innenrand.
- Abschattung gibt es nur als Innenradius kreisförmiger Aperturen; Spinnen und andere Formen sind nicht modelliert.

**Umsetzung:**
- PR A: rtt-trace, das Flag und `stop_radius`.
- PR B: Referenzstrahlen der Analysen und des Optimierers, `stop.clips_beam`.
- PR C: Ringzellen der Pupillenfunktion und Abnahme gegen die Ringpupille (ADR 0033).

## Nachtrag (#229, PR C, 2026-10-11): Ringzellen der Pupillenfunktion

Ergänzt Punkt 1 für eine zentrale Abschattung am Stopp (Plan zu #229, E4).

**Warum exakte Flächenanteile auch am Innenrand:** Die Treppe am Innenrand (Zelle verloren, sobald ihr Abtastpunkt in der Abschattung liegt) hat einen Fehler O(1/N) wie die verworfene Treppe am Außenrand (H2b). Ein Prototyp (Python, Ringpupille ε = 0,4, Zellen mit exakten Anteilen) zeigt den Unterschied an der ersten Nullstelle der PSF bei N = 64/128:
- Treppe: Schranke e = 2|X₆₄ − X₁₂₈| = 4,3·10⁻³, über der Toleranz 10⁻³;
- exakte Anteile: e = 4,2·10⁻⁶.

**Zellen:** `pupil_cells(N, ε)` gibt die Zellen des Rings ε ≤ |p| ≤ 1.
- f = f₁ − f_ε: f₁ ist der Anteil im Einheitskreis (Punkt 1), f_ε der Anteil im Innenkreis aus derselben geschlossenen Form, mit den Koordinaten durch ε geteilt (Fläche mal ε², Momente mal ε³).
- Gespiegelt und vertauscht wird wie beim Einheitskreis, Spiegel- und Tauschbilder sind also bitgleich.
- Abtastpunkt ist der Schwerpunkt des Ringteils, (f₁ a² c₁ − M_ε)/(f a²).
- Eine Zelle ganz im Innenkreis hat f = 0 exakt und wird nicht getraced; eine Zelle außerhalb des Innenkreises ist bitgleich die des Vollkreises.
- Mit ε = 0 ist das Ergebnis bitgleich `pupil_cells(N)`.

**ε aus dem Stopp:** ε = r_i/|R_s|, mit r_i dem Innenradius der kreisförmigen Stoppapertur und |R_s| = `trace::stop_radius()` bei der ausgewerteten Wellenlänge (Nachtrag #229 oben).
- Mit realem Zielen ist der Rand der Abschattung genau der Pupillenkreis |p| = ε, innerhalb `kAimTolerance`.
- ε steht als `PupilFunction::obscuration` im Ergebnis. ε ≥ 1 ist ein `AnalysisError` an `/paths/i`.
- Eine Abschattung auf einer anderen Fläche geht nicht in ε ein. Ihre Zellen enden real verloren, als Treppe (Grenze, siehe oben).

**Zellen auf dem Innenrand** (`PupilCells::inner_rim`) werden als virtuelle Referenzstrahlen getraced:
- Ihr Ringteil ist nicht konvex, sein Schwerpunkt kann im Innenkreis liegen.
- Die Fläche entscheidet, der Strahl tastet nur W und A ab.
- Die übrigen Zellen bleiben reale Strahlen.

**Strahl-Operanden des Optimierers** (`ray_value`, ADR 0030, Punkt 3) sind Stichproben und bleiben real (Zweitprüfung #245): Ein Operand bei p = (0, 0) in einem abgeschatteten System ist NaN („lost before or at it“), während der Spot-Bezug denselben Strahl virtuell nimmt. Für einen Bezug ohne Abschattung dient der Hauptstrahl-Bezug.

**Zernike:** Auf dem Ring sind die Noll-Polynome nicht orthogonal, auch wenn jede Zelle ankommt. `zernike_fit` warnt deshalb mit `zernike.pupil_incomplete` („annular pupil“). Ringpolynome wären ein eigenes Issue.

## Nachtrag (#265, 2026-10-13): nominaler Bezug für Spot und OPD

**Anlass:** Gestörte Prüflinge der Toleranzierung sind nicht rotationssymmetrisch; `first_order` lehnt sie ab, und damit fehlen Zielung und Austrittspupille der Referenzsphäre (ADR 0036, Punkt 2, Entscheidung des Maintainers: nominaler Bezug).

**Entscheidung:**
- Neuer Werttyp `NominalReference` (`rtt/analysis/nominal_reference.hpp`), erzeugt mit `nominal_reference(nominal, path)` aus dem kompilierten Nennsystem (je Pfad und Konfiguration): je Systemwellenlänge die Zieldaten `trace::AimReference` (ADR 0007, Nachtrag #252) und die Mitte E = (0, 0, z_XP) der paraxialen Austrittspupille an der Referenzwellenlänge, keine bei XP im Unendlichen. Undurchsichtig, mit geteiltem, unveränderlichem Inhalt: billig zu kopieren. Scheitert die Rechnung für eine Wellenlänge oder die XP, wirft der Bezug die gemerkte Ausnahme mit gleichem Typ erst dort, wo die Analyse sie braucht.
- `SpotOptions` und `OpdOptions` haben das Feld `std::optional<NominalReference> reference` (Entscheidung des Koordinators: Feld statt Überladungen, wie `focus_shift`). Mit Bezug:
  - Alle Strahlen und Hauptstrahlen (auch die virtuellen Referenzstrahlen des Nachtrags #229) werden mit `reference.aim(λ)` gezielt und konvergieren auf die Blende des Prüflings.
  - Referenzsphäre: Mitte C am Durchstoßpunkt des Hauptstrahls der Referenzwellenlänge des Prüflings auf seiner Bildfläche (wie ohne Bezug), Radius |C − E| mit E aus dem Nennsystem; `focus_shift` und die Verzweigung wie bisher. Der Bildraumindex n′ kommt aus dem Prüfling.
  - Der Bezug muss zum Pfad des Aufrufs gehören (`std::invalid_argument`); die weitere Passung (Pfad, Wellenlängen, Felder, Objekt, Apertur) prüft `trace::AimReference` beim Zielen.
- Ohne Bezug unverändert; mit dem Bezug aus demselben System bitgleich (dieselben Zahlen aus derselben Rechnung, Test über alle Referenzdateien).
- **Grenze (M7):** nur `spot`, `opd_points`, `opd_map` und `opd_fan` nehmen den Bezug, das sind die Analysen hinter den Kriterien und Operanden (ADR 0030, ADR 0035, Punkt 7). `ray_fan`, Verzeichnung und Bildfeldwölbung, die Farbfehler sowie Pupillenfunktion, PSF, MTF, Jones-Pupille und Zernike-Fit rechnen weiter mit den paraxialen Daten des analysierten Systems und lehnen einen gestörten Prüfling mit `ParaxialError` ab; sie bekommen den Bezug bei Bedarf in einem eigenen Issue.

## Nachtrag (#286, 2026-10-30): Grenze der affinen Zuordnung

Entscheidung des Maintainers in #286: kurzfristig ablehnen statt nur warnen, langfristig die vektorielle Debye-PSF (#284).
- **Option** `PupilFunctionOptions::mapping_limit` (Standard 0,05) in [0, 1], neben `mapping_warning`. NaN oder ein Wert außerhalb ergibt `std::invalid_argument`. Eine Ordnung zu `mapping_warning` gibt es nicht: Beide Schwellen sind unabhängig, und `mapping_limit < mapping_warning` ist erlaubt.
- **Feld** `PupilFunction::mapping_limit`: `pupil_function` kopiert die Option, `refocus` übernimmt sie. `pupil_function` selbst lehnt nie ab. Abgelehnt wird erst in den FFT-Analysen (ADR 0033, Nachtrag #286).
- **1 schaltet die Prüfung ab:** Bei `mapping_limit` = 1 wird nie abgelehnt, unabhängig von δ_max. Das gilt ausdrücklich, denn δ_max ≤ 1 gilt nicht allgemein; nur bei der idealen Linse ist δ ≤ 1 − cos θ_max.
- **Ideale Linse** (ADR 0031, tan θ = h/f) mit t = tan θ_max: s(ρ) = ρt/√(1 + ρ²t²), |M| = t, also δ(ρ) = ρ(1 − 1/√(1 + ρ²t²)). Bei ρ = 1 ist das 1 − cos θ_max: 0,134 bei NA 0,5 und 0,564 bei NA 0,9. Diese Systeme verletzen die Sinusbedingung (Punkt 4), und ihre FFT-PSF wäre um tan θ/sin θ zu schmal (Messung in #286).
- Ergebnisformat: ADR 0023, Nachtrag #286.
