# ADR 0010: Lizenz MIT

**Status:** angenommen (2026-10-04)

## Entscheidung

Projekt unter MIT. Abhängigkeiten nur mit kompatiblen Lizenzen: MIT, BSD, Apache-2.0, BSL-1.0, MPL-2.0 (unverändert), LGPL nur dynamisch gelinkt. Herstellerkataloge (Glas, Lagerlinsen) werden nicht mitgeliefert.

## Verworfen

GPL-Abhängigkeiten.
