# ADR 0039: Blende auf einer Fläche (`aperture.stop`, Schema 0.8)

**Status:** angenommen (Koordinator im Auftrag des Maintainers, #53; Zweitprüfung f2)

## Kontext

Die Systemblende ist heute ein eigenes Element `stop` mit genau einer Fläche (`ElementKind::Stop`, „1 Fläche mit Apertur, höchstens einer pro System“, `docs/architecture.md`, Modell). In klassischen Designs ist die Blende aber oft die Fassung einer Linsen- oder Spiegelfläche, z. B. beim Cooke-Triplet nach Sasián/Geiser die Vorderfläche von L2 (#34) oder der Hauptspiegel eines Teleskops. Dafür gibt es nur Behelfe (#53):

- eine ebene Blende im Scheitel: außeraxial falsch, weil die gekrümmte Fläche davor liegt;
- eine deckungsgleiche gekrümmte Blende: Schnitt bei t = 0 < t_min = 1e−9 mm, der Strahl verfehlt sie;
- in #34 eine ebene Blende 1e−8 mm hinter dem Scheitel von L2.S1, im Glas, auf einem expliziten Pfad (`transmit`). Den Fehler schätzt der Stop-Shift-Satz ab (`test_m2_acceptance.cpp`, Kommentar „Stop:“).

**Bestand im Code (main f3ebcc8):**
- Das Modell kennt die Blende nur über die Elementart. `CompiledSystem` hat kein Blendenfeld. Alle Nutzer nehmen das **erste** Ereignis eines Pfads an einer Fläche eines `Stop`-Elements, jeweils mit eigener Schleife:
  - `rtt-trace/src/sources.cpp` (`make_context`);
  - `rtt-paraxial/src/paraxial.cpp` (`Step::stop`, Pupillen);
  - `rtt-optim/src/parabasal.cpp` (`stop_event`);
  - `rtt-analysis/src/common.hpp` (`LossCounter`, `stop.clips_beam`, vergleicht den Flächenindex);
  - `rtt-analysis/src/pupil.cpp` (`stop_obscuration`);
  - `rtt-analysis/src/reports.cpp` (`SystemReport::stop`);
  - `rtt-compile` (`require_stop`, `check_stop_on_paths`, `NoStopError`).
- **Zielung** (ADR 0007): `stop_hit()` schneidet die tatsächliche Form der Blendenfläche und vergleicht die lokalen (x, y) des Treffpunkts mit dem Ziel σ·p·R_s. Für eine gekrümmte Fläche ist das schon richtig: Es ist dieselbe Projektion wie der Aperturtest der Fläche (`inside_aperture`).
- **Paraxial:** Die Pupillen sind die Bilder der Blende in ihrer Scheitelebene. Die Rückrechnung beginnt **hinter** dem Blendenschritt (`propagate(steps, stop + 1, …, front.n_out, …)`, Kommentar „the stop itself only transmits“). Für eine brechende oder spiegelnde Blendenfläche ginge damit deren Brechkraft und Indexwechsel in der Austrittspupille verloren.
- **Toleranzierung:** Ein Prüfling zielt mit den nominalen Zieldaten (Ereignisindex der Blende, r_EP, stop_scale), trifft aber die Fläche des gestörten Systems an diesem Ereignis (ADR 0036, Punkt 2; ADR 0007, Nachtrag #255). Eine gestörte Blende nimmt das Ziel also mit.
- **Ghosts** (ADR 0027): Reflexionskandidaten sind die `refract`-Ereignisse des Grundpfads; die Blende (`transmit`) ist keiner. Ghost-Pfade werden nicht selbst gezielt, die Bewertung zielt auf dem Grundpfad.

**Vorgaben (Koordinator, Welle 2):** ein gemeinsamer Schemasprung 0.8 mit #288 (ADR 0038) und #296. Den Sprung macht der Formats-PR von #288; dieser ADR fügt sein Feld innerhalb von 0.8 hinzu. Höchstens eine Blende im System.

**Entscheidungen des Maintainers (#53, 2026-10-31):**
1. Das Feld steht in `aperture` (`aperture.stop`).
2. Zulässig sind Flächen von `lens`, `mirror`, `plate` und `thin_element`.
3. Neues Referenzsystem `m2/cooke_triplet_surface_stop`; `m2/cooke_triplet` bleibt unverändert.
4. Die Blendenfläche braucht eine Apertur.

**Reihenfolge der PRs (Koordinator):**
1. f2: Umbau `object_z()`;
2. Formats-PR #288 mit dem Sprung auf 0.8;
3. PR A dieses ADR: bitgleicher Umbau `stop_event`, Punkt 3;
4. PR B: Format, Punkte 1, 2, 4 und 8 bis 10.

## Entscheidung

### 1. Feld

Die Systemapertur bekommt das optionale Feld `stop` mit der Bezugsform aus ADR 0038, Punkt 1 (`{"surface": "<id>"}`, `$defs/surface_reference`):

```json
"aperture": {"type": "epd", "value": 12.5, "stop": {"surface": "L2.S1"}}
```

Die Apertur dieser Fläche ist die Systemblende. Fehlt das Feld, gilt das heutige Verhalten: Blende ist das `stop`-Element, falls vorhanden.

Im Modell: `SystemAperture::stop` als `std::optional<SurfaceId>`. Bearbeitungsform (ADR 0024): `/aperture/stop`.

Warum in `aperture`: Der Aperturwert (`epd`, `object_na`, `stop_size` …) und der Ort der Blende beschreiben zusammen die Systemapertur. `stop_size` nimmt dann den Radius der Flächenapertur.

### 2. Höchstens eine Blende

Ein System hat entweder ein `stop`-Element oder `aperture.stop`, nie beides. Die Blendenfläche ist eine Fläche eines Elements der Art `lens`, `mirror`, `plate` oder `thin_element`. Ein Verweis auf die Fläche eines `stop`- oder `detector`-Elements ist ein Fehler. Das `stop`-Element bleibt für freistehende Blenden; keine Migration entfernt es.

### 3. Compile: eine Stelle für die Blende

`CompiledSystem::stop_surface()` gibt den Index der Blendenfläche (`std::optional<std::uint32_t>`, wie `CompiledEvent::surface` und `find_surface()`): die Fläche des `stop`-Elements oder die Fläche aus `aperture.stop`. `compile::stop_event(system, path)` gibt das **erste** Ereignis des Pfads an dieser Fläche, gleich welcher Art (`refract`, `reflect`, `transmit`). Alle Nutzer aus dem Bestand lesen nur noch diese beiden Funktionen. `require_stop`, `NoStopError` und `stop.not_on_path` gelten unverändert mit dieser Definition.

Der Umbau kommt **zuerst als eigener PR ohne Formatänderung** (wie `object_z()` in ADR 0038, Punkt 4): Die Funktionen finden dort nur das `stop`-Element, alle Ergebnisse bleiben bitgleich.

Das Ereignis der Blendenfläche behält seine Art: Eine Linsenfläche bricht, ein Spiegel reflektiert. Nur das `stop`-Element ist `transmit` (wie heute).

### 4. Paraxial

- Die Blendenebene ist wie heute die Scheitelebene der Blendenfläche (paraxial zählt die Pfeilhöhe nicht).
- Eintrittspupille: Bild der Blende durch die Schritte **vor** der Blendenfläche (`propagate(steps, 0, stop, …)`, unverändert). Die Blende liegt vor der Brechung an ihrer eigenen Fläche, y ist dort stetig.
- Austrittspupille: Bild der Blende durch die Blendenfläche **selbst** und alle Schritte danach. Für eine Flächenblende beginnt die Rückrechnung beim Blendenschritt (`propagate(steps, stop, …, z_stop, front.n_out, …)`): Der Transfer über 0 mm ist exakt, danach bricht oder spiegelt die Fläche mit ihrem Index. `front.n_out` ist dabei der Index **vor** der Blendenfläche: `front` endet mit den Schritten [0, stop), also vor dem Blendenschritt. Der Name legt „danach“ nahe, gemeint ist das Medium, in dem die Rückrechnung beginnt. Für das `stop`-Element bleibt `stop + 1` (bitgleich; der Schritt ist dort ein Durchgang ohne Wirkung, ihn mitzurechnen könnte n·u/n runden).
- Dasselbe gilt für die Betragsrechnung der Unendlich-Prüfung (`magnitude_trace`, #35 B9 und #280).
- Der Radius für `stop_size` und die Prüfung „needs a circular aperture for the pupils“ nehmen die Apertur der Blendenfläche.
- Seidel (Stop-Shift, Hauptstrahl durch die Blendenmitte) und `trace_ray` brauchen keine Änderung: `trace_ray()[stop].y` ist die Höhe im Scheitel der Blendenfläche vor deren Brechung.

### 5. Zielung (ADR 0007)

Keine neue Regel. `stop_hit()` wendet die Ereignisse vor der Blende an, schneidet dann die Blendenfläche mit ihrer Form und vergleicht die lokalen (x, y) mit σ·p·R_s, R_s = |r_EP · stop_scale| aus der Scheitelebene.
- Der Hauptstrahl trifft so die Flächenmitte (lokal 0, 0) auf der gekrümmten Fläche.
- Ein Randstrahl trifft die Fläche dort, wo ihr Aperturtest den Radius R_s misst.
- Die Brechung an der Blendenfläche gehört nicht zum Residuum; nur der Treffpunkt zählt.
- Die Fortsetzung aus #287 und die Signatur der Zieldaten (#255) gelten unverändert. Die Signatur vergleicht die Ereignisse und die Systemapertur, also künftig auch `aperture.stop`.

Bei einem Spiegel als Blende ist das Ereignis `reflect`. Das Ziel liegt ebenso in lokalen Koordinaten der Spiegelfläche.

### 6. Pfade und Ghosts

- Ein Pfad, der die Blendenfläche mehrfach trifft (Doppelpass, Ghost), nimmt das erste Ereignis, wie heute beim Element.
- Eine Flächenblende auf einer brechenden Fläche ist ein Reflexionskandidat des Ghost-Generators (ADR 0027): Das ändert die Zahl der Ghosts gegenüber dem `stop`-Element. Beim Triplet gibt es mit beiden Formen 6 brechende Flächen, also 15 Ghosts, denn STO zählt beim Element nicht mit und L2.S1 ist ohnehin brechend.
- Ein Spiegel als Blende ist ein `reflect`-Ereignis und damit kein Reflexionskandidat (ADR 0027: nur `refract`). Die Zahl der Ghosts ändert sich durch ihn nicht.
- In einem Ghost-Pfad kann das erste Ereignis an der Blendenfläche ein `reflect` sein. Für die Bewertung ist das ohne Folgen, weil sie auf dem Grundpfad zielt.
- `stop.clips_beam` vergleicht den Flächenindex. Eine Vignettierung an der Blendenfläche bei irgendeinem Durchgang zählt, wie heute.

### 7. Toleranzierung (ADR 0036)

Die Blende folgt der gestörten Fläche. Wird L2 dezentriert oder gekippt oder ändert sich der Radius von L2.S1, liegt das Ziel σ·p·R_s in den lokalen Koordinaten der gestörten Fläche (ADR 0036, Punkt 2). r_EP, stop_scale und σ bleiben nominal.

Das ist gewollt und physikalisch richtig: Die Fassung sitzt an der Linse. Es ist der bewusste Unterschied zum Objektbezug von ADR 0038, Punkt 5, der am nominalen Ort bleibt. Die Klassenexpansion braucht keine Sonderregel: Die Items der Linse bewegen ihre Fläche und damit die Blende.

### 8. Prüfungen (`validate`)

Namensraum `stop.*`; keine gemeinsamen Codes mit ADR 0038.
- `stop.surface_unknown` (Fehler, `/aperture/stop`, neu): keine Fläche dieser id.
- `stop.surface_kind` (Fehler, `/aperture/stop`, neu): die Fläche gehört zu einem `stop`- oder `detector`-Element (Punkt 2).
- `stop.multiple` (bestehend): ein `stop`-Element **und** `aperture.stop`. Ort `/aperture/stop`.
- `stop.aperture_missing` (bestehend): die Blendenfläche hat keine Apertur. Ort `…/surfaces/k/aperture` der Fläche.
- `aperture.stop_missing` (bestehend): `stop_size` ohne `stop`-Element und ohne `aperture.stop`. Der Text wird angepasst.
- `stop.not_on_path` (compile, bestehend): unverändert mit der Definition aus Punkt 3.
- **Keine Kreisapertur:** Eine Rechteck- oder Ellipsenapertur auf der Blendenfläche bleibt ein Laufzeitfehler bei den Pupillen (`ParaxialError` „needs a circular aperture for the pupils“), wie heute beim `stop`-Element. Ein eigener `validate`-Code nur für `aperture.stop` wäre uneinheitlich. Für beide Formen eingeführt, machte er heute gültige Dateien ungültig: Mit einer nicht kreisförmigen Blende lassen sich Strahlen ohne Zielung weiter verfolgen. Eine frühe Prüfung für beide Formen kann ein eigenes Issue werden.

### 9. Format und Migration

- Das Feld kommt innerhalb von 0.8 (Sprung im Formats-PR von #288, ADR 0038, Punkt 8). Keine eigene Migration.
- Ein `aperture.stop` in einer Datei vor 0.8 ist ein Lesefehler an `/aperture/stop`.
- Bestehende Dateien bleiben bis auf die Version bitgleich.
- Lesen: `aperture` nimmt `stop` als Bezugsform. Schreiben: nur wenn gesetzt, nach `value`.
- JSON-Schema: `aperture.properties.stop` mit `$ref` auf `$defs/surface_reference`.
- `docs/dateiformat.md`: Abschnitt Systemapertur und Tabelle der Elementarten („`stop`: freistehende Blende; Blende auf einer Fläche siehe `aperture.stop`“).

### 10. Python

- `raytatouille.model.SystemAperture.stop`: eine `SurfaceReference` (Attribut `surface`) wie `ObjectSpace.reference` aus ADR 0038, Punkt 9, oder None. Der typisierte Baum spiegelt so die Datei.
- Bearbeitung über den Editor (`/aperture/stop`). Kein neues Ergebnisformat.
- `SystemReport.stop` nennt die Blendenfläche wie bisher.

## Verworfen

- **Flag an der Fläche** (`"stop": true` in einer Fläche oder ihrer Apertur): „höchstens eine Blende“ müsste `validate` über den ganzen Baum prüfen. Ein Verweis ist eindeutig und steht dort, wo die Systemapertur beschrieben ist.
- **Verweis auf der obersten Ebene** (`system.stop`): Der Ort der Blende gehört zur Systemapertur. `stop_size` braucht beide zusammen.
- **Das `stop`-Element abschaffen** und alle Blenden als Verweis auf eine Fläche schreiben: Eine freistehende Blende hat keine Linsenfläche. Die Migration müsste Elemente löschen und verschöbe relative Lagen (ADR 0028, `relative_to_preceding`).
- **Blendenebene in der Pfeilhöhe** statt im Scheitel: paraxial unüblich. Die reale Zielung trifft die gekrümmte Fläche ohnehin.
- **Zielung auf die Tangentialebene im Scheitel:** wäre der Behelf „ebene Blende im Scheitel“ und außeraxial falsch.

## Folgen

- Die Nutzer der Blende werden zu zwei Funktionen gebündelt; der Umbau ist ein eigener, bitgleicher PR.
- `paraxial.cpp`: Die Rückrechnung für eine Flächenblende beginnt beim Blendenschritt.
- Neues Referenzsystem `tests/reference/m2/cooke_triplet_surface_stop.rtt.json`: das Triplet aus #34 ohne STO, mit Pfad `auto` und `aperture.stop = {"surface": "L2.S1"}`, L2.S1 mit der Apertur des bisherigen STO (Radius 10). `m2/cooke_triplet.rtt.json` bleibt unverändert, denn die M2-Abnahme und viele Bitvergleiche hängen daran.
- **Tests:**
  - **Umbau-PR:** alle Tests unverändert (bitgleich); `stop_surface()` und `stop_event()` für Element, kein Stop, Doppelpass und Ghost-Pfad.
  - **Formats-PR, Triplet mit Flächenblende gegen #34:**
    - erste Ordnung: f, BFL und FFL bitgleich zum Behelf (unabhängig von der Blende). z_EP gegen den unabhängigen y-ν-Wert ohne Versatz aus #34, 11.679209257540240 mm, auf 1e−9 mm. Inhaltswache: Der Behelf liegt bei 11.679209268268448, die Differenz 1,07e−8 mm ist erkennbar.
    - Seidel: je brechender Fläche gegen ray-optics und Sasián wie in der M2-Abnahme (ray-optics hat die Blende genau auf L2.S1), mindestens so genau wie der Behelf. Gegen den Behelf innerhalb der Stop-Shift-Schranke aus #34 (|ΔS| < 0,65e−9 mm).
    - **reale Strahlen, Hauptstrahlen gegen den Behelf** (Schranke unten): Der Bildpunkt jedes Felds stimmt mit dem des Behelfs auf B_f überein. Inhaltswache: Der Hauptstrahl der Flächenblende trifft L2.S1 lokal bei (0, 0) innerhalb von kAimTolerance; der des Behelfs trifft L2.S1 bei |y| ≈ |ū_Glas|·δ (2,0e−9 mm bei 14°, 2,9e−9 mm bei 20°).
    - **reale Strahlen außerhalb des Hauptstrahls: kein Vergleich mit dem Behelf**, sondern gegen die Definition. Jeder gezielte Strahl trifft L2.S1 lokal bei σ·p·R_s innerhalb von kAimTolerance. Der Behelf ist dort eine andere Blende, nämlich die ebene Blende im Scheitel aus #53 (bis auf 1e−8 mm): Derselbe Pupillenpunkt trifft L2.S1 um den Weg im Glas zwischen Pfeilhöhe und Ebene versetzt, etwa ū·Pfeilhöhe. Gemessen mit dem Behelf auf main: auf der Achse 1,27e−2 mm bei p = ±1 (Pfeilhöhe −0,452 mm, Steigung 0,028); bei 20° bis 0,141 mm bei p = −1 (3 % von R_s = 4,666 mm). Inhaltswache: Diese Abweichung ist bei den Strahlen des Behelfs messbar groß (> 1e−3 mm bei p = ±1).

**Schranke für die Hauptstrahlen (hergeleitet zu #53, Messung mit dem Behelf auf main, Skript im PR):**
- Der Behelf zielt den Hauptstrahl auf die Mitte von STO, δ = 1e−8 mm hinter dem Scheitel von L2.S1 im Glas. Die Flächenblende zielt ihn auf die Mitte von L2.S1. Die beiden Ziele trennt auf L2.S1 die Höhe ε_f. Der Test nimmt ε_f **zur Laufzeit** als den gemessenen lokalen Betrag |y_L2| des Hauptstrahls des Behelfs auf L2.S1 (aus den aufgezeichneten Pfaden), nicht die paraxiale Schätzung |ū_Glas|·δ. Die Schätzung erklärt nur die Größe: gemessen 0 / 2,0e−9 / 2,9e−9 mm für 0°, 14°, 20°. Dazu kommt die Zielgenauigkeit kAimTolerance = 1e−9 mm je Lauf.
- Der Bildpunkt hängt vom Treffpunkt auf L2.S1 über k_f ab. k_f ist der Differenzenquotient Δy_Bild/Δy_L2 der beiden gezielten Strahlen des Behelfs bei p = (0, ±1e−3): Beide Größen sind gemessen (y_Bild auf IMG, y_L2 lokal auf L2.S1), ohne Umrechnung über Pupillenkoordinaten. Gemessen: 0,0036 / 0,0008 / −0,0147. Über 1e−8 mm ist die Abbildung linear bis auf O(ε²), das ist vernachlässigbar.
- Schranke je Feld: B_f = 2·(ε_f + 2·kAimTolerance)·|k_f| + 1e−12 mm. Der Faktor 2 ist Reserve für die Messung von k_f; 1e−12 mm deckt die Rundung der Bildkoordinate (|y| ≤ 20 mm, ε_M·20 ≈ 4e−15). Erwartet: unter 2e−10 mm. Gemessen wurde ε_f·|k_f| ≤ 4,3e−11 mm.
- x: Die Felder liegen in y, die Fächer sind symmetrisch. x wird gegen dieselbe Schranke geprüft.

**Folge für das Abnahmekriterium von #53** („identische Ergebnisse (Seidel, Pupillen, Strahlen)“): Identisch im Rahmen der Stop-Shift-Schranke sind die paraxialen Größen (erste Ordnung, Pupillen, Seidel) und die Hauptstrahlen. Alle anderen realen Strahlen unterscheiden sich physikalisch, weil der Behelf eine ebene Blende ist. Dort ersetzt der Test gegen die Definition den Vergleich.
    - Austrittspupille: Lage und Durchmesser gegen einen unabhängigen y-ν-Trace der Blendenmitte durch L2.S1 bis L3.S2 (Rechnung im PR). Inhaltswache: Ohne die Brechung an L2.S1 (alter Code) weicht der Wert deutlich ab.
  - **Spiegel als Blende:** `m2/paraboloid_stop` ohne Stop-Element, Blende auf dem Spiegel: EP im Spiegelscheitel, Durchmesser = EPD; Hauptstrahl trifft die Spiegelmitte.
  - **Toleranzierung:** Eine Dezentrierung von L2 verschiebt das Ziel, und der Hauptstrahl trifft die gestörte L2.S1 lokal bei (0, 0). Eine Dezentrierung von L1 tut das nicht.
  - **Ghosts:** 15 Ghosts wie beim Behelf, die Bewertung läuft.
  - `validate`-Codes, I/O-Roundtrip, `aperture.stop` in einer 0.7-Datei ist ein Lesefehler, Schema-Tests, Python liest und bearbeitet `aperture.stop`.
- `docs/architecture.md` (Konventionen, Blende) und `docs/dateiformat.md` werden ergänzt.

## Umsetzung

- PR A (#341): der bitgleiche Umbau aus Punkt 3. Nachweis mit einem vorübergehenden Marker, der die alte Suche mitrechnete, über alle C++- und Python-Tests; kein Unterschied.
- PR B: Format, Prüfungen, Paraxial, Python und die Tests aus „Folgen“. Abweichungen von Fassung 3 des Entwurfs:
  - `stop_surface()` liefert `std::optional<std::uint32_t>` statt `std::size_t` (Punkt 3).
  - Python: `SystemAperture.stop` ist eine `SurfaceReference` statt eines Texts (Punkt 10).
  - Erste Ordnung gegen den Behelf: relativ ≤ 1e−12 statt bitgleich. Der Behelf teilt den Transfer L2.S1 → L2.S2 an STO in zwei Schritte, die anders runden können.
